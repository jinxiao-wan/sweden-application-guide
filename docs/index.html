全流程概览

  1. 注册与选校注册 University Admissions，浏览目标项目。
  2. 核对要求在项目官网核对先修课、英语要求、专用材料及提交入口。
  3. 排序与提交按就读意愿排序并提交，在 Application 核对项目和申请编号。
  4. 交材料与查结果提交支持材料、缴费或证明免缴，随后查看账户消息。
