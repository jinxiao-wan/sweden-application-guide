# 瑞典留学申请指南

**[打开网站 →](https://jinxiao-wan.github.io/sweden-application-guide/)**

一份中文 DIY 申请指南，主要面向中国大陆本科背景、准备申请瑞典硕士的同学。网站目前整理了 **2027 年秋季第一轮**的申请时间线、材料清单和常见问题。

## 怎么用

| 你现在想做什么 | 从这里开始 |
| --- | --- |
| **第一次申请，想了解整个流程** | [全流程概览](https://jinxiao-wan.github.io/sweden-application-guide/#guide) · 从注册选校、核对项目要求，到提交志愿和查看录取结果。 |
| **想知道什么时候交申请、缴费和补材料** | [申请时间线](https://jinxiao-wan.github.io/sweden-application-guide/#timeline) · 按时间查看申请开放、志愿提交、材料与缴费截止、录取结果公布。 |
| **正在准备成绩单、学信网报告或文书** | [材料文件清单](https://jinxiao-wan.github.io/sweden-application-guide/#materials) · 选择「已毕业」或「本科最后一年」，按实际需要逐个勾选文件。进度保存在当前浏览器。 |
| **想查具体问题、找官网或下载模板** | [信息汇总检索库](https://jinxiao-wan.github.io/sweden-application-guide/#library) · 搜索「CSSD」「雅思」「课程描述」等关键词，或按资料类型筛选。这里也有在职证明和课程描述模板。 |

## 提交前核对

不同项目对先修课、文书和提交入口的要求可能不同。准备材料前，先看 [University Admissions 的中国大陆硕士申请材料说明](https://www.universityadmissions.se/en/apply-to-masters/provide-application-documents-masters/country-instructions/china-mainland/)，再到目标项目官网核对当季的要求。站内指南和个人经验供参考，具体要求以招生平台和院校发布的信息为准。
